# AGENTS.md — legacy

> 作用域：`legacy/`。继承[根协作规则](../AGENTS.md)；这是废弃/归档区，默认只读。

## 职责

- 保存已移除实现和历史上下文，供审计与迁移参考；不属于现役运行链。

## 局部规则

- 现役 `service`、`engines`、`decision` 等核心模块不得 import 本目录。
- 不从归档代码启动进程、连接交易所、恢复资金费率套利或复用旧下单路径。
- 修复现役问题时不要直接复活 legacy 实现；先提取仍有效的需求和安全约束再重新设计。
- 移入/移出/删除归档内容必须有用户明确意图，并同步入口、引用和代码图。
- 历史代码中的参数、接口和收益结论不代表当前事实。

## 最小验证

- `python3 tools/code_graph.py --check`
- 若迁移代码到现役模块，按目标模块 `AGENTS.md` 执行完整专项与全量验证。
