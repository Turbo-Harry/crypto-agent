# OKX Chrome 页面实时采集

用途：把用户主动启用的 OKX 标签页可见正文作为研究证据送入本机模拟盘服务。该扩展不持有交易能力，
不读取表单、密码框或可编辑内容，也不能修改策略、模型、仓位或风控。

## 安装

1. Chrome 打开 `chrome://extensions`，开启开发者模式。
2. 选择“加载已解压的扩展程序”，目录为 `tools/chrome_news_capture/`。
3. 打开 `https://www.okx.com/` 或 `https://my.okx.com/` 页面。
4. 点击扩展，选择“监听当前 OKX 标签页”。若服务设置了 `CRYPTO_AGENT_API_TOKEN`，在扩展中填入同值。
5. 本机模拟盘服务必须运行在 `127.0.0.1:8091`。

## 数据语义与边界

- 只采集启用标签页当前可见文本、页面标题、URL、语言和路径；DOM 变化 1.5 秒后节流发送。
- 页面隐藏时不采集；相同内容使用 SHA-256 幂等去重。
- 服务端最多保存每个事件 20,000 字符；列表接口不返回正文，避免无意扩散页面内容。
- 数据进入 `browser_page_events`，当前只作研究证据。OKX REST/WebSocket 仍是行情事实源。
- OKX 页面改版、虚拟列表、地区域名或登录弹窗可能改变可见文本，不能把 DOM 当作可靠行情接口。

## 验证

查看 `GET http://127.0.0.1:8091/browser/okx/events`，确认启用页面后出现新事件。写入端点仅接受回环
Host，并在配置 API token 时要求 `x-api-token`。
