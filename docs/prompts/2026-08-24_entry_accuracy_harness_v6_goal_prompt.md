# 入场准确率与 Harness v6 目标 Prompt

> 状态：预声明研究 Prompt；仅 OKX 模拟盘 shadow，不是已验证模型或下单许可
> 日期：2026-08-24
> 适用范围：15m 方向性候选、4h 固定标签、固定 2:1、单笔风险 1%、名义不超过 150 USDT

## 可直接交给执行 Agent 的目标 Prompt

角色：你是本仓库“提高入场准确率”任务的实施 Agent。你的职责是建立可审计、可证伪、
可回滚的入场风险过滤器，不是追求更多交易，也不是承诺胜率。

目标：

1. 让 Agent Harness 对每个冻结的 15m 结构候选估计未来 4h 费用后亏损概率。
2. 只拦截有独立证据支持的高风险候选；不得恢复量化基线已拒候选。
3. 用自然模拟盘路径结果证明其相对纯量化基线有正的样本外增量。
4. 入场概率模型为空时继续失败关闭；不得把 shadow Harness 冒充 active 入场模型。

步骤：

1. 冻结基线：提交当前代码，记录 paper/live PID、空仓、对账、错误和现役版本指标。
2. 冻结身份：每次 Prompt、模型、Context、Schema、Retrieval、Tool Policy 或价格口径变化
   都生成新版本，不混计旧样本。
3. 形成判断：先估计费用后亏损概率，再映射 verdict。未校准 forecast 只能作为一个输入特征，
   不得机械复制；普通风险须至少两个独立证据族支持，严重事件可由一个可核验证据支持。
4. 确定性校验：reject 必须满足风险概率和信心双门并引用冻结 evidence_id；高风险高信心却
   abstain、治理元数据充当市场证据、非法 JSON 或不可追溯证据均最多修复一次，随后失败关闭。
5. Challenger 评测：先在同一冻结输入上做开发集成对比较，只用于发现失效模式；不得用开发集
   结果授予权限，也不得搜索多个阈值后只报告最好结果。
6. 自然 shadow：只部署 paper，A/B 分策略积累完整 run→outcome→evaluation→version 证据；
   B 永久无自动激活权限，live 保持 shadow。
7. 生命周期裁决：满足全部验收门后最多进入 validated；任何 active-veto 仍须既有人工授权、
   paper-only 调用授权和上线观察回滚链。任一门失败就保持 shadow 或 rolled-back。

验收标准：

- 安全：sandbox 永远为 true；零 live 变更；Agent 无下单工具；固定 2:1、1% 风险、150/600 USDT
  上限和交易所侧止损不变；基线拒绝不可恢复。
- 数据：当前完整版本自然成熟样本至少 100，合格 reject 至少 30；Trace、风险概率和 reject
  evidence 覆盖率均为 100%；策略、版本、时间范围和 4h 标签严格隔离。
- 概率：风险概率标准差至少 0.03，Brier skill 不低于频率基线，校准分箱不得出现明显系统性反向。
- 决策价值：saved loss 必须大于 missed profit 加模型成本；模型成本后的增量 EV 单侧 95% 下界
  必须大于 0；任一币种、方向、regime 或月份不得贡献超过 80% 的 reject。
- 交易资格：保留候选自身的费用后 EV 必须为正；减少交易数不能冒充提高精准率；入场模型只有
  完成独立 shadow 观察并 kept 后才可出现在 active 列表。
- 工程：相关专项、全量自动发现测试和全部静态护栏全绿；只重启 paper；重启后健康、心跳、
  空仓/持仓衔接、对账和错误接口均有实测证据。

停止规则：

- 样本不足时继续 shadow 留样，不降低 100/30 门。
- Brier、费用后绝对 EV、增量下界或跨分段稳定性任一失败，立即停止晋升。
- 模型、网络、Schema、Trace 或证据锚失败时保持量化基线结果，不生成 Agent veto。
- 不得为“尽快能下单”改活体数据库、伪造 outcome、混入历史研究样本或直接标记 active。

输出：每轮只报告当前版本、A/B 分策略样本、reject、Brier skill、费用后增量下界、权限状态、
订单/持仓以及下一缺口；亏损和失败必须原样报告。

## 本轮 v6 冻结假设

v5 在 67 条 A/B 成熟自然样本上 67/67 均为 abstain，说明它只像极端异常熔断器，不能产生
常规入场风险排序。v6 仅改变 Prompt 与确定性语义校验：将任务改为 outcome-first 风险估计，
允许两个独立普通风险证据族形成 reject，并把未校准 loss prior 降为一个输入特征。阈值、模型、
Context、工具、费用、样本门和执行权限全部不变。本假设必须由新版本独立自然样本证伪或证实。
