# AGENTS.md — backtest

> 作用域：`backtest/`。继承[根协作规则](../AGENTS.md)；回测只用于研究和证伪，不授予交易权限。

## 职责

- 策略历史重放、训练/测试切分、成本模拟与实验比较。

## 局部规则

- 严格避免未来函数、幸存者偏差、重复市场机会和训练/测试污染。
- 手续费、滑点、资金费、成交可达性和时间对齐必须显式；不报告未扣成本的“收益”结论。
- 参数搜索与最终评价分离；保留试验宇宙、随机种子、数据版本和拒绝结果。
- 回测通过不能证明 live/paper 正期望，失败结果不得删除、挑选或美化。
- 不读取活体数据库、不下单、不修改模型生命周期或风险预算。

## 最小验证

- 运行受影响的 replay、forecast、factor/overfit 专项。
- 用固定输入验证可复现、as-of 与成本语义。
- `python3 tools/code_graph.py --check`
